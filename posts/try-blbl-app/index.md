# 云视听小电视的优缺点
（原链接：https://xn--kiv765b.top/upload/MkAAqz6WRJ - 2026-04-25T160553.290.png：来自：哔哩哔哩官网的云视听小电视下载页面，源站图片已失效）

## 优点

1. 云视听小电视官方出品更稳定不会出现用着用着就用不了
2. 功能完善
3. 品类足，分区细
4. 对遥控器的支持比较好
5. 可以投屏，可以使用哔哩必连
6. 有家庭模式，可以给家人使用
7. 多账号共存

优点暂且这么多，接下来是缺点

## 缺点

这根本说不完

1. 不能看 UP 直播（除 B 站官方央视等）
2. 不能看 UP 最新发的视频
3. （这是我最不能忍受的一点）视频是经过筛选的，小 UP 的视频根本看不到
4. 会员专享权益需要开通超级大会员（这个缺点除人傻钱多 [是谁懂的都懂] 的以外）
5. 广告
6. 没有字幕显示
7. 倍速太低，倍速最快也只有两倍速
8. 对触摸屏操作支持的不友好

其他的话就不说了

# 那有没有弥补云视听小电视缺点点的软件呢

有的，说的就是 Blbl

当然，有优点那就会有缺点

# Blbl的优缺点
（原链接：https://xn--kiv765b.top/upload/推荐页 - 2026-04-25T194714.983-zXjT.png，源站图片已失效）

## 优点

云视听小电视的所有缺点他都可以满足

## 缺点

1. 对遥控器的操作不友好，对触摸屏的支持也很一般
2. 不稳定，如果不能用，你需要重新去到 Github 上面下载它的最新版
3. 不能投屏和使用哔哩必连
4. 不可以做账号内存
5. 分区比较粗，没有多少的分区
6. 没有家庭模式，在电视上运行肯定得要考虑是否有家庭模式的，毕竟你家人的兴趣和你的兴趣也不一样
7. Bug 也非常多

Blbl 的缺点也是说不完的

如果你能接受这个缺点，那你就下载

# 兼容性如何

一般电视或机顶盒都是安卓，也有不是的比如 IOS 或 Linux 的

这个软件只能在安卓电视上运行
（原链接：https://xn--kiv765b.top/upload/Screenshot_20260425_175459_bin.mt.plus.canary.jpg，源站图片已失效）

这个安装包没有 lib 文件夹的话，说明这个安装包可能是采用纯 Java 或 Kotlin 编写的，没有包含任何 CPU 架构相关的原生代码，这种情况下一般 32 位和 64 位的安卓设备都能安装运行。

我们再来看签名状态
（原链接：https://xn--kiv765b.top/upload/Screenshot_20260425_175454.jpg，源站图片已失效）

有 V1+V2，依然可以在 32 位的设备上运行

你可以将这个安装包拷贝到 U 盘里给电视安装，或者使用 ADB 安装
